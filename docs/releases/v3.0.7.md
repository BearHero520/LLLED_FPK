## 安装与升级

下载 `App.Native.UGreenLED-3.0.7.fpk` 或同内容的 `App.Native.UGreenLED.fpk`，
在 fnOS 应用中心选择手动安装。应用标识仍为 `App.Native.UGreenLED`，支持覆盖升级并保留配置。
`App.Native.UGreenLED-3.0.7.fpk.sha256` 对应带版本号安装包。

二维码阅读器修复随安装包更新；已有用户需要升级应用，单独刷新 README 不会更新阅读器。
