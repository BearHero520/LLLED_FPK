# UGreen Control v3.0.5

项目由 LLLED_FPK 迁移至 [UGreen-Control](https://github.com/BearHero520/UGreen-Control)，新项目默认分支为 `main`。LLLED_FPK 的 `almighty` 合入 `main` 后同步发布此迁移版本；配套 UGREEN-NAS-Hardware 的 `Almighty` 也合入其 `main`。

- 在线更新、下载链接和应用内项目说明统一指向 [UGreen-Control Releases](https://github.com/BearHero520/UGreen-Control/releases/latest) 及新仓库 README。
- 保留 `App.Native.UGreenLED` 应用标识，可在 fnOS 应用中心覆盖升级并保留配置。
- 包含 Almighty 现有 BIOS、风扇、独立 WOL/RTC、DXP6800 支持及界面改进；硬件实现继续由 UGREEN-NAS-Hardware 提供，LED 请求统一通过包内 CLI。
- DXP6800 原厂曲线仍未知，兼容预设使用 Pro 参数。本版本未新增 NAS 实机写入或关机唤醒验证；各机型限制以应用检测及硬件文档为准。

下载 `App.Native.UGreenLED.fpk` 或带版本号的同内容文件，通过 fnOS 应用中心手动安装。SHA-256 文件对应带版本号的 FPK。
