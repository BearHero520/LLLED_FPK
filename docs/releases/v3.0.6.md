# UGreen Control v3.0.6

本版本正式发布，同步使用 [UGREEN-NAS-Hardware v0.3.0](https://github.com/BearHero520/UGREEN-NAS-Hardware/releases/tag/v0.3.0)
的新硬件包，保留 `App.Native.UGreenLED` 应用标识，支持在 fnOS 应用中心覆盖升级并保留配置。

- 整体更新四个 Linux x86_64 硬件程序及十个机型插件，来源统一为上游 `main` 提交
  `754fdfb29badb045d5a214fbf687fc167f8cb86f`。
- 固定发布标签、源码子模块、归档和 manifest SHA-256，导入时验证逐文件载荷与源码提交。
- 保留独立 WOL/RTC、物理网口选择、DXP6800 三路风扇遥测、自定义曲线和 Pro 参数兼容预设。
- 同步最新上游说明与验证日志，移除先前局部扩展的源码快照，避免混用不同构建来源。

正式硬件包的能力状态仍标记 `experimental-incomplete`；应用正式发布不代表全部机型
已完成实机验证。DXP6800 原厂温控曲线仍未知，兼容预设采用 Pro 参数。本次没有新增
NAS 寄存器写入、实际关机唤醒或逐 BIOS 兼容性验证。

下载 `App.Native.UGreenLED-3.0.6.fpk` 或同内容的 `App.Native.UGreenLED.fpk`，
通过 fnOS 应用中心手动安装。`App.Native.UGreenLED-3.0.6.fpk.sha256` 对应带版本号安装包。
