# Web 设计约定

- 信息架构固定为：概览、灯光设置、活动提示、设备与高级。
- 桌面使用窄侧栏，窄屏切换为顶部导航；模式控制保持在底部浮动栏。
- 视觉采用亮色液态磨砂：浅色画布、半透明表面、克制阴影和高对比正文。
- 页面依赖必须随 FPK 离线提供，禁止使用公网 CDN。
- 图标统一使用 Bootstrap Icons；应用品牌图继续使用 `images/logo.png`。
- 主内容区、表格与诊断面板均应保留可见但克制的自定义滚动条。
- 桌面端优先保持常用操作单屏可见：灯光设置采用分类切换，诊断原始数据默认折叠，短窗口自动启用紧凑间距。
- 主内容区随窗口宽度扩展，最大宽度为 1480px；硬盘与 LED 映射表格必须独占整行并完整展示五列。
